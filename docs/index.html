Relay Pairing Android

Installable Android bridge shell for pairing with the secure SMS relay used by the Relay Desk web console.

Download debug APK

Pairing steps

  1. Install the APK on the authorized Android device.
  2. In the relay administrator session, call POST /auth/pairings and copy the one-time code and device key.
  3. Open the APK and enter the relay HTTPS URL, pairing code, and device key.
  4. After activation, the APK stores the device key using Android Keystore-backed encrypted storage.
  5. Configure the SMS web console with the same relay URL and administrator login.

Security

The device key is never placed in this page or in a URL. Use HTTPS for the relay, keep the pairing code private, and revoke the device if the phone is lost.

Relay request

POST /v1/pairing/activate
Content-Type: application/json

{"pairing_code":"...","device_key":"..."}
